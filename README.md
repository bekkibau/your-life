# your life

A visual life calendar — see your time as a grid of weeks/months/years, subtract the hours consumed by sleep, work, screens, and the rest, and find out how much is truly yours.

Single-file HTML app. No build step, no dependencies.

[Tim Urban's "Your Life in Weeks"](https://waitbutwhy.com/2014/05/life-weeks.html) meets an interactive daily-hours calculator.

## Run locally

Just open `index.html` in a browser.
